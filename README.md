# 化妆镜 (makeup-mirror)

VR 化妆小游戏 prototype：面对一面镜子，用手柄上的刷子给自己化妆。three.js + WebXR。

## 运行

```bash
npm install
npm run dev
```

- **桌面**：打开 `https://localhost:5173`（自签名证书，浏览器提示时选"继续访问"）。在镜子里的脸上按住左键拖动来画。
- **Pico**：电脑和头显连同一个 Wi-Fi，在 Pico 浏览器打开终端里显示的 `https://<电脑IP>:5173`，接受证书后点 "ENTER VR"。

## VR 操作

- 两只手柄各有一把刷子，笔尖颜色就是当前工具的颜色
- 用笔尖碰一下台面上的化妆品就能换工具；碰"全部卸妆"瓶子会清空妆容
- 把笔尖贴到自己脸上（真实的脸前方），看着镜子画；按得越深，笔触越大，手柄也会震动
- **拍照**：碰搁板上的相机，或按 A / X。拍立得照片会贴到镜子右边的墙上
- **化妆挑战**：碰铃铛，或按 B / Y。脸会被清空，镜子左边出现目标妆容和 2 分钟倒计时；画好后再碰一下铃铛提交（时间到也会自动提交），得分会写在自动拍下的照片上

桌面版：`P` 拍照（右侧相册点击可下载），`C` 开始 / 提交挑战，`空格` 低头看搁板。

## 代码结构

| 文件 | 内容 |
|---|---|
| `src/main.js` | 场景、镜子（`Reflector`）、手柄、桌面鼠标输入、主循环 |
| `src/avatar.js` | Q 版角色（卡通着色 + 描边），只放在镜子相机能看到的图层；顶部 `LOOK` 改发色、瞳色、衣服颜色 |
| `src/faceCanvas.js` | 脸部贴图：底层画五官，上层是妆容，卸妆只擦上层 |
| `src/tools.js` | 化妆品定义（颜色、笔刷大小、软硬）、台面道具、刷子模型 |
| `src/photo.js` | 拍照：专用相机渲染头肩照（左右翻转，和镜子里一致）、拍立得排版、墙上的照片墙 |
| `src/challenge.js` | 化妆挑战：4 种目标妆容（和脸部贴图同一套 UV 坐标画出来）、打分、倒计时、墙上的挑战板 |
| `src/sfx.js` | 用 WebAudio 合成的快门、铃声等音效（不需要音频文件） |
| `src/room.js` | 房间、拱形镜框和灯泡、梳妆台和装饰（贴图都用 canvas 程序生成） |

## 关键实现

- **只在镜子里看到自己**：角色放在图层 5，主相机看不到，镜子的反射相机（`mirror.camera`）能看到。图层 1 和 2 被 three.js 留给了 XR 的左右眼，所以不能用
- **头部不延迟**：设置 `renderer.xr.cameraAutoUpdate = false`，每帧先手动调用 `updateCamera`，再摆放头部，然后渲染
- **画到脸上**：从头部中心经过笔尖做射线，打到头部球面，拿到 UV 后在画布上盖章；两帧之间按间距补点，快速划动时笔画也是连续的
- **桌面鼠标**：鼠标射线打到镜面，按镜面法线反射，再打到真实的头
- **贴图局部上传**：脸部贴图是 2048×1024，整张上传对头显太慢，所以画画时只把笔刷碰到的区域通过 `copyTextureToTexture` 上传
- **卡通外观**：`MeshToonMaterial` 三阶色带，加上"反向外壳"描边（背面沿法线外推、画成深色）。头发用 alpha 遮罩裁出一簇簇的刘海边缘
- **大头对准真脸**：角色的眼睛对齐你真实眼睛的位置，所以大头的脸正面和你真实的脸大致重合，刷子贴脸的手感不变
- **挑战打分**：在脸部区域（缩小到 80 像素宽，可以容忍几毫米的偏差）逐像素比较"你的妆让颜色偏移了多少"和"目标让颜色偏移了多少"，误差按妆量归一化。所以素颜或画错妆容是 0 分，完全一样是 100 分，画重或画淡只扣一部分
