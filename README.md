# 化妆镜 (makeup-mirror)

VR 化妆小游戏 prototype：面对一面镜子，用手柄上的刷子给自己化妆。three.js + WebXR。

## 运行

```bash
npm install
npm run dev
```

- **桌面**：打开 `https://localhost:5173`（自签名证书，浏览器提示时选"继续访问"）。在镜子里的脸上按住左键拖动来画。
- **Pico**：电脑和头显连同一个 Wi-Fi，在 Pico 浏览器打开终端里显示的 `https://<电脑IP>:5173`，接受证书后点 "ENTER VR"。

## VR 操作

- 两只手柄各有一把刷子，笔尖颜色就是当前工具的颜色
- 用笔尖碰一下台面上的化妆品就能换工具；碰"全部卸妆"瓶子会清空妆容
- 把笔尖贴到自己脸上（真实的脸前方），看着镜子画；按得越深，笔触越大，手柄也会震动

## 代码结构

| 文件 | 内容 |
|---|---|
| `src/main.js` | 场景、镜子（`Reflector`）、手柄、桌面鼠标输入、主循环 |
| `src/avatar.js` | 角色（头、五官、头发、身体），只放在镜子相机能看到的图层 |
| `src/faceCanvas.js` | 脸部贴图：底层画五官，上层是妆容，卸妆只擦上层 |
| `src/tools.js` | 化妆品定义（颜色、笔刷大小、软硬）、台面道具、刷子模型 |

## 关键实现

- **只在镜子里看到自己**：角色放在图层 5，主相机看不到，镜子的反射相机（`mirror.camera`）能看到。图层 1 和 2 被 three.js 留给了 XR 的左右眼，所以不能用
- **头部不延迟**：设置 `renderer.xr.cameraAutoUpdate = false`，每帧先手动调用 `updateCamera`，再摆放头部，然后渲染
- **画到脸上**：从头部中心经过笔尖做射线，打到头部球面，拿到 UV 后在画布上盖章；两帧之间按间距补点，快速划动时笔画也是连续的
- **桌面鼠标**：鼠标射线打到镜面，按镜面法线反射，再打到真实的头
